# Parte A - Contador persistente

Seleccione version/setstate, version/riverpod o version/bloc desde la raíz.
Después, en esta carpeta: `flutter pub get`, `flutter run`.
Las versiones tienen la misma interfaz, main.dart como entrada y domain/data
idénticos. No se usa un selector ni --dart-define para alternar implementaciones.
Para comprobar: `flutter analyze --no-pub`, `flutter test --no-pub`.
Las respuestas y la tabla están en ../RESPUESTAS.md.
